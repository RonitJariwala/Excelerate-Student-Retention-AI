## 📌 Overview

This repository contains the final project for the **Excelerate AI-Powered Data Insights Virtual Internship (July-Aug 2025)**. This four-week project transformed raw learner engagement data into a scalable framework for improving student retention. It covers the full data science lifecycle, from data cleaning and exploratory analysis to building a predictive churn model and a proactive, personalized recommender system.

---
## ✨ Key Features

* **Data Cleaning & Feature Engineering:** Processed and cleaned over 8,558 records and engineered 6 new features to enrich the dataset for analysis.
* **Predictive Churn Modeling:** Built a Random Forest Classifier that achieves **90% accuracy** and **91% recall** in effectively identifying at-risk students before they drop out.
* **Content-Based Recommender System:** Developed a proactive recommendation engine that delivers personalized and timely opportunities to re-engage learners based on their unique profiles.

---
## ⚙️ Tech Stack

* **Python**
* **Pandas** for data manipulation and analysis
* **Scikit-learn** for building the Random Forest model
* **Matplotlib & Seaborn** for data visualization
* **Jupyter Notebook** for development and documentation

---
## 📊 Key Insights & Recommendations

* **Insight:** The analysis identified a **14% global decline in signups** from 2023 to 2024, with Asia being the most affected region.
* **Insight:** The predictive model revealed that **Opportunity Duration** is the most significant factor driving student churn.
* **Recommendation:** Deploy the recommender system for ongoing, proactive retention and launch targeted re-engagement campaigns for underrepresented demographics to boost engagement.

## 🚀 Installation & Usage

1.  Clone the repository:
    ```bash
    git clone [https://github.com/RonitJariwala/Excelerate-Student-Retention-AI.git](https://github.com/RonitJariwala/Excelerate-Student-Retention-AI.git)
    ```
2.  Navigate to the project directory:
    ```bash
    cd Excelerate-Student-Retention-AI
    ```
3.  Create and activate a virtual environment (recommended):
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```
4.  Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```
5.  Launch Jupyter and navigate to the `notebooks/` directory to explore the project.
    ```bash
    jupyter notebook
    ```
