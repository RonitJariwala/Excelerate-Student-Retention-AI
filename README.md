## 📌 Overview

[cite_start]This repository contains the final project for the **Excelerate AI-Powered Data Insights Virtual Internship (July-Aug 2025)**[cite: 1, 10, 12, 192, 194, 205]. [cite_start]This four-week project transformed raw learner engagement data into a scalable framework for improving student retention[cite: 15, 26, 189, 206]. [cite_start]It covers the full data science lifecycle, from data cleaning and exploratory analysis to building a predictive churn model and a proactive, personalized recommender system [cite: 15, 17-20, 22-25, 206-208].

---
## ✨ Key Features

-   [cite_start]**Data Cleaning & Feature Engineering:** Processed and cleaned over 8,558 records and engineered 6 new features to enrich the dataset for analysis[cite: 22, 44, 207, 224, 226].
-   [cite_start]**Predictive Churn Modeling:** Built a Random Forest Classifier that achieves **90% accuracy** and **91% recall** in effectively identifying at-risk students before they drop out[cite: 24, 86, 88, 207, 294, 295].
-   [cite_start]**Content-Based Recommender System:** Developed a proactive recommendation engine that delivers personalized and timely opportunities to re-engage learners based on their unique profiles[cite: 20, 25, 149, 150, 208, 301, 311].

## 📊 Key Insights & Recommendations

-   [cite_start]**Insight:** The analysis identified a **14% global decline in signups** from 2023 to 2024, with Asia being the most affected region[cite: 23, 57, 58, 238, 342].
-   [cite_start]**Insight:** The predictive model revealed that **Opportunity Duration** is the most significant factor driving student churn[cite: 91, 282].
-   [cite_start]**Recommendation:** Deploy the recommender system for ongoing, proactive retention and launch targeted re-engagement campaigns for underrepresented demographics to boost engagement[cite: 184, 186, 348, 351].

## 🚀 Installation & Usage

1.  Clone the repository:
    ```bash
    git clone https://github.com/RonitJariwala/Excelerate-Student-Retention-AI.git
    cd Excelerate-Student-Retention-AI
    ```
2.  Create and activate a virtual environment (recommended):
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```
3.  Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```
4.  Launch Jupyter and navigate to the `notebooks/` directory to explore the project.
    ```bash
    jupyter notebook
    ```
